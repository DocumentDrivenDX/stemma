# Stemma repository instructions

- Stemma is content (templates, prompts, methodology) plus one skill: `skills/stemma/SKILL.md`. Do not add separate public `stemma-*` skills; add modes to the one skill.
- Stemma's own documents are governed by HELIX: see `.helix.yml` and `docs/stemma/`. Use `/helix` to frame, design, and align them.
- Invariants: no citation without a verified source record; every draft claim traces to the claim ledger.
- Keep changes minimal and specified before implemented.
