Stemma

A plugin in the making that helps scholars research, write and typeset books with AI: it checks citations with scripts, explains what it finds, and aims to trace each cited claim to a stored source.

Pre-release. A first part of the command line works. Most of what Stemma is meant to do is not built. See what works today.

Try it on macOS See real output

The name

A stemma codicum is the family tree of a text's manuscripts: it shows which copy derives from which. Stemma aims to give a book the same property, so that each cited claim has a line of descent to a stored source.

How it is meant to work

Two strands run together. This describes the design, not what is built.

  • Evidence strand: source records, reading notes with page-level locators, constructs, places, and a ledger tying claims to the sources that support them, kept as plain files.
  • Manuscript strand: thesis, outline, chapter specifications, drafts and the assembled book.

What it does today

It sets up a project, adds records, checks the record format, runs two bibliography checks and warns about coordinates written in project files. Each finding says what is wrong, shows the evidence, says why it matters and suggests what to do.

Part of a family

Stemma belongs to DocumentDrivenDX. Its own documents are specified with HELIX, which authors do not need.
