Quick start on macOS

Run the first slice of the command line from a checkout.

Set up and tried only on macOS on Apple silicon. Intel Macs, Windows and Linux are untested, and the setup script stops on them. Installing the plugin from a marketplace for everyday use is not ready.

You need

  • git, and the curl and openssl commands that macOS includes.
  • A network connection on the first run, to fetch the pinned Bun and the development packages from the npm registry.

Run the demo

The script checks the Bun download against a pinned hash and keeps what it fetches inside the checkout. It installs nothing system-wide. All names and sources in the demo are invented. These steps need a checkout that holds this slice; if the repository's default branch does not hold it yet, a fresh clone will not have it.

Run your own command

Build first. The project path must be absolute.

Keep all three flags: without them Bun can download packages, or load a bunfig.toml or .env from the working directory. To start a project, replace check with init.
