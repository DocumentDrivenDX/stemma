What works today

Built and planned are kept apart. Anything not in the first list does not work yet.

Works today (command line only)

  • init creates a project; record add adds a record from a JSON file.
  • validate, fmt and rules check check and tidy record files and standing rules.
  • check runs 4 checks (bib.uncited, cite.key, coordinate.stray, record.valid), each with stated limits, and writes a text or JSON report.
  • version and doctor say what is running.

check keeps no change baseline yet, so it always checks the whole project. A project is not called checked clean while it holds something this version cannot check.

Tried only on macOS on Apple silicon. No desktop app host and no release has been tested.

Planned, not built

  • Taking over a Word manuscript and its reference libraries; reading manuscript files at all.
  • Storing copies of sources, extracting their text, and checking quotations and locators against them.
  • Reading notes, a claim ledger, model support verdicts, review marks and annotations.
  • A browser explorer for the evidence graph, argument and geographic maps and typeset pages. There is no web interface to Stemma today: this site is documentation.
  • Typesetting with Typst, with Chicago notes and bibliography first.
  • Voice and style profiles.
  • Delivery of the command line through a plugin marketplace, in Claude desktop on macOS and Windows first, and in ChatGPT and Codex later.
  • 30 further checks that are named but not built.
