Get started

Install one plugin, then ask Claude in plain words. There is nothing else for you to set up.

What you need

Claude Code. A folder for your project. Your own copies of the works you cite, for example PDFs.

Stemma is pre-release. It has been tried on one Mac with Apple silicon, including installation with the Claude command-line tool (Stemma 0.0.1). The Claude desktop app, a live Claude session using the plugin, Windows and Linux are untested. On Windows, setup needs Git Bash.

Install the plugin

Type these two commands in a terminal. They add the DocumentDrivenDX catalog of plugins and install Stemma from it.

The first time you use it

Stemma needs a small program called Bun to run. Claude downloads one fixed version, confirms it is the expected file, and keeps it inside the plugin's own folder. Your system settings stay as they are, and Claude asks permission as it usually does.

If setup fails, or you say no, Claude tells you that nothing was checked. You can keep writing either way.

What to ask Claude

“Start a Stemma project in this folder.”
Creates the project files and overwrites nothing.
“Add a source record for this book, taking the details from its title page.”
Writes a record of the work. Claude says where each detail came from.
“Keep this PDF as my copy of that source. I downloaded it from the library today.”
Puts the file in your private store, noting where and when you got it.
“Read the text of that copy and work out its page numbers.”
Reads the text inside the PDF, or takes a text file, and proposes page numbers for review where the printed numbers support them.
“Record the citations in this chapter.”
Writes one record for each citation, with its sentence, page and quotation.
“Check the project and explain what is open.”
Runs the checks and explains each finding. When a quotation differs, you see it beside the closest wording in your copy.
“What does that book say on page 89?”
Shows only the pages you ask for, up to five, marked as quoted from the source.
“I have a better scan of this book. Replace the old one.”
Keeps the new copy, sets the old one aside, and lists what relied on it.
“Is anything missing from my source store?”
Names every stored file that is missing or has changed.

The tools behind these requests are tested. A live Claude session following the plugin's instructions has not been tested.

Before you add material

Anything in a project may be sent to the AI model. Stemma holds back no individual source. If you may not send something to a hosted model, do not put it in the project.

Back up your private store. Your copies and their text live outside the project, and Stemma makes no other copy of them.
