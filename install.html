Install and ask Claude

Installing the plugin is the only installation there is. The plugin and Claude set up everything else themselves.

Stemma is not published to a marketplace, so this page gives no install command. Installation through the plugin's marketplace entry has been tried with the Claude command-line tool on one Mac, using a local stand-in for the distribution repository. The Claude desktop app, Windows and Linux are untested.

What happens on first use

Claude fetches a pinned copy of the Bun runtime from the npm registry, checks it against a digest shipped in the plugin, and keeps it in the plugin's own data directory. It changes no system or shell setting, and Claude's usual permission prompts apply. If setup fails or you decline it, Claude says that nothing was checked, and your writing carries on.

What to ask Claude

You askStemma does
“Start a Stemma project in this folder.”Creates the project files and overwrites nothing.
“Add a source record for this book, taking the details from its title page.”Writes a record of the work. Claude says where each detail came from.
“Keep this PDF as my copy of that source. I downloaded it from the library today.”Stores the file in a private store outside the project, with its digest, origin and the time you got it.
“Attach the text of that copy, with its page breaks.”Saves a plain-text file, or a text layer for a PDF or scan, page by page. A page gets a printed number only from stated evidence.
“Record the citations in this chapter.”Writes one record for each citation, with its sentence and page.
“Check the project and explain what is open.”Runs the checks and explains each finding in plain language.
“Is anything missing from my source store?”Names every stored file that is missing or has changed.

The commands behind these requests are tested. A live Claude session following the plugin's skill has not been tested.

Your copies stay yours

Copies of sources and their text go to a private store outside your project, never into it. Backing that store up is your job. Stemma is for material that may be sent to a language model: it holds back no individual source.
