Stemma demo. All names and sources are invented.
DEMO is a fresh temporary directory
STEMMA_STORE_DIR is set to $DEMO/store, the private content store, outside the project.
"stemma" below is the command line inside the plugin. In use, Claude runs it for the author.

=============== 1. Create a project and record two sources

$ stemma init --project $DEMO/book

  wrote rules.md
  wrote .gitattributes
  wrote .gitignore
  wrote stemma.json
[exit 0]

1. PROBLEM: A source is listed for the built bibliography but cited nowhere.  [bib.uncited]
   Why it matters: The bibliography would list a work the book never cites, or a citation you meant to make is missing.
   What to do: Cite it, remove it from bibliography_include in stemma.json, or keep it on purpose and record why.

       source file: records/sources/src-demo0orphan001.json
       key: orphan1990

2. PROBLEM: A citation uses a key that no source record holds.  [cite.key]
   Why it matters: A reader or a build cannot tell which source this citation means, so it cannot be checked or put in the bibliography.
   What to do: Correct the key in the citation, or add a source record with that key (or add it to the right source's key_aliases).
   - cit-demo0toll00002
       citation file: records/citations/cit-demo0toll00002.json
       key: hartwel1998
       sentence: The toll was doubled in the following century.

3. PROBLEM: A file is not written in the canonical form (key order, indentation or line endings differ).  [record.valid]
   Why it matters: Digests, review marks and diffs depend on one exact form. No value is wrong because of this alone.
   What to do: Run `fmt` on the file. It rewrites the layout and changes no value.
   - stemma.json
       file: stemma.json

4. PROBLEM: A cited source has no stored copy, so this citation is unchecked.  [source.held]
   Why it matters: Without a stored copy and its text, nobody can compare this citation with the source, so it is unchecked.
   What to do: Add your copy (`source add <file> --source <id>`). For a book you hold only on paper, add a scan and attach its text. Writing can carry on meanwhile.

       citation file: records/citations/cit-demo0toll00001.json
       key: hartwell1998
       source file: records/sources/src-demo0harbour01.json

Why it matters: a mistake of one of these kinds would go unnoticed. What to do: check them by hand where they matter.

   - whether cited figures appear in the stored source text  [number.present]
